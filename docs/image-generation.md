# Image Generation

Paid image generation costs money or plan credits per call. Make images
yourself first: HTML/CSS/SVG rendered locally (headless Chrome), Pillow
composites, and assets already in the project. When a local image will not
do, ask before calling a paid image tool (OpenAI `gpt-image-*`, Gemini,
Codex's built-in image generation, Claude Code's media-pipeline
`image-generation` skill / CLI / `create_asset`): say which tool, how many
images and what for, then wait for a yes. A request that explicitly asks for
a generated image is the yes for that request only. Never call one on your
own; this overrides any skill that says to generate images automatically.
